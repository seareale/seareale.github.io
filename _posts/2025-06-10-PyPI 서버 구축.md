## ✅ Devpi 소개

Devpi는 다음과 같은 기능을 제공합니다:

- PyPI 미러 프록시 (인터넷 없이 pip install 가능)
- 사내 전용 패키지 업로드/배포
- 여러 인덱스(user/index)로 권한 분리

## 🐳 Docker로 Devpi 서버 배포

**폴더 구조**
```
┬─ config
├─ server-data
├─ Dockerfile
├─ build.sh
├─ devpi.yaml
└─ docker-compose.yaml
```

**Dockerfile 및 yaml 파일**

```yaml
# devpi.yaml
# ldap 설정을 위한 파일로 필요없는 경우 무시
devpi-ldap:
  url: ldap://ldap.srai.internal
  tls: false
  referrals: false
  user_template: uid={username},cn=users,dc=ldap,dc=srai,dc=internal
  group_search:
    base: cn=users,dc=ldap,dc=srai,dc=internal
    filter: (&(objectClass=posixAccount))
    attribute_name: CN
```

```yaml
version: "3.8"
services:
  devpi:
    build: .
    container_name: devpi-docker
    ports:
      - "53141:3141"
    volumes:
      - ./server-data:/data
      - ./config:/config
```

```docker
# Dockerfile
FROM python:3.10-slim

# 필수 도구 설치
RUN apt-get update && apt-get install -y build-essential libldap2-dev libsasl2-dev && \
    pip install --no-cache-dir \
        devpi-server \
        devpi-client \
        devpi-ldap

# 포트
EXPOSE 3141

# 설정 파일 복사
COPY ./devpi.yaml /config/devpi.yaml

# 데이터 볼륨
VOLUME ["/data"]
RUN devpi-init --serverdir /data

# 실행
CMD ["devpi-server", "--restrict-modify", "seoreu", "--serverdir", "/data", "--host", "0.0.0.0", "--outside-url", "https://pypi.seoreu.com", "--ldap-config", "/config/devpi.yaml"]
```

**도커 실행**

Devpi 서버가 [http://localhost:3141](http://localhost:3141/) 에서 실행됩니다.

```bash
# 실행
docker-compose up -d
```

## 👨‍💻 개발자가 Devpi 사용하기

### 1. pip 설치

```bash
pip install --index-url https://pypi.seoreu.com/seoreu/dev {설치할 패키지 명}
```

## 🚀 패키지 업로드 및 공유(관리자 계정만 가능)

<aside>
💡

**도커 실행 시 사용했던 `--restrict-modify` 옵션으로 관리자 계정만 가능한 기능**

</aside>

### 1. Devpi 클라이언트 설치

```bash
pip install devpi-client
```

### 2. 인덱스 생성(옵션)

```bash
devpi index -c {원하는 index 명} bases=seoreu/pypi # 인덱스 생성
devpi index -y --delete seoreu/{삭제할 인덱스} # 인덱스 삭제
```

### 3. Python .whl 빌드(추천)

- `cibuildwheel` 를 사용하는 경우, python 버전 별로 자동 빌드가 가능함

```bash
devpi index -c {원하는 index 명} bases=seoreu/pypi # 인덱스 생성
devpi index -y --delete seoreu/{삭제할 인덱스} # 인덱스 삭제
```

- `pyproject.toml` 를 작성한 경우, 더 세세한 옵션 설정이 가능함


### 4. 패키지 빌드

```bash
python -m build  # 예시, 레포에서 정한 빌드 명령어로 실행 또는 `cibuildwheel` 이용
```

### 5. Devpi에 업로드

```bash
devpi use https://pypi.seoreu.com/seoreu/dev
devpi login seoreu
devpi upload # 해당 명령어는 python -m build를 수행함

# 아래는 dist 폴더에 만들어진 .whl 파일을 업로드하는 명령어
# powershell
Get-ChildItem dist\*.whl | ForEach-Object { devpi upload $_.FullName }

# cmd
for %f in (dist\*.whl) do devpi upload "%f"

# bash
for f in dist/*.whl; do devpi upload "$f"; done
```

- `seoreu/dev`는 공용 인덱스 이름입니다.
- 도커 실행 시 사용했던 `-restrict-modify` 옵션으로 `seoreu` 사용자 외에는 인덱스 및 패키지를 생성/삭제 불가능합니다.
